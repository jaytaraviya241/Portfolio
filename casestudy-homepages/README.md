# Case-study image library

Capture date: 2026-08-26

Every verified project contains:

- `desktop-home.png` — 1920 × 1080 PNG
- `mobile-home.png` — 1170 × 2532 PNG

`project-covers/` contains the presentation artwork used by portfolio cards. Cover filenames follow `<project-slug>-cover.png`; generated timestamp names are intentionally not used. Projects without dedicated cover artwork fall back to their desktop capture.

Mobile screenshots are rendered from a true 390 × 844 CSS viewport at 3× device scale, producing 1170 × 2532 PNGs without resizing or cropping the responsive layout.
